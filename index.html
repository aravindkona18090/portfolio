🚗 FlexiRide — Architecture & System Design

Full-Stack Campus Mobility Platform • Benchmark: 9.6 / 10

📌 1. System Overview & Motivation

FlexiRide is a full-stack, bike-first and carpooling web platform designed for campus communities and daily commuters. It eliminates high solo-commute costs and campus traffic by algorithmically matching drivers and passengers with transparent cost-sharing and safety verification.

🧠 2. Core Mathematical & Algorithmic Models

  • Dynamic Tiered Pricing Engine: Implements marginal distance pricing curves:
    • Bike: ₹10 base + ₹3/km (first 10km) → ₹2/km (10–30km) → ₹1.50/km (30–60km) → ₹1.20/km (>60km)
    • Car: ₹20 base + ₹5.50/km (first 10km) → ₹4/km (10–30km) → ₹3/km (30–60km) → ₹2.20/km (>60km)
    • Peak Surge: ×1.25 multiplier during morning entry (8–10 AM) & evening exit (4–7 PM).
    • EV Incentive: 10% eco-discount for electric vehicles.
  • Atomic Concurrency & Seat Locking: Solves race conditions and double-booking using conditional MySQL transactions: UPDATE rides SET seats_available = seats_available - ? WHERE id = ? AND seats_available >= ?
  • Weighted Trust & Safety Rating (0–100%):
    Score = 20 (Base) + 30 (Phone OTP) + 35 (Aadhaar Verified) + 15 (DL Audit).
    Tiered badges: Gold Shield (≥80%), Blue Shield (50–79%), Silver Shield (<50%).
  • Geospatial Haversine Formula: Calculates great-circle spatial distance between coordinate pairs without paid external API overhead.

🏛️ 3. Normalized Database Schema (3NF) & Security

  • Schema Entities: 3NF-normalized tables for users, user_verifications, user_emergency_contacts, vehicles, rides, bookings, messages, ratings.
  • Identity Verification: Aadhaar numbers verified mathematically using the Verhoeff algorithm (dihedral group \(D_5\)).
  • Security Hardening: 100% prepared SQL statements, BCRYPT password hashing, CSRF session tokens validated via hash_equals(), and binary MIME-type upload checks (finfo) with UUID renaming.
  • Emergency SOS Automation: One-touch HTML5 GPS panic button generating live Google Maps links and alerting emergency contacts.

🏛️ CivicConnect — Architecture & System Design

Smart Municipal Intelligence Platform • Google Gemini Vision AI

📌 1. System Overview & Mission

CivicConnect is an end-to-end, AI-powered smart city governance and municipal grievance redressal platform. It automates civic workflows between citizens, field officers, and administrators to ensure verified, rapid resolution of public infrastructure issues (potholes, garbage, broken streetlights, water leakage).

🏛️ 2. Three-Tier Role-Based Architecture

  • 👤 Citizen Portal (/peoplelogin): AI camera scanner with automatic category detection and severity rating, Leaflet.js GPS location pinning, voice-to-text input (Web Speech API), 24/7 CivicBot AI chat (EN, TE, HI, KN), and Before vs. After resolution photo comparison.
  • 👷 Field Officer Portal (/workerlogin): Task inspection workspace with 1-click turn-by-turn Google Maps GPS driving directions, citizen click-to-call cards, 1-click dynamic AI translation, and photographic proof-of-work evidence uploader.
  • 🛡️ Municipal Admin Portal (/adminlogin): Central intelligence dashboard with department workload filters, severity heatmaps, proximity-based officer allocation, and visual Before vs. After audit verification before closing tickets.

🧠 3. AI Engines, Deduplication & Security

  • Google Gemini Multimodal Vision AI (gemini-3.6-flash): Analyzes uploaded complaint photos in real time, auto-categorizes municipal departments, rates severity levels (Low, Medium, High, Critical), and generates human-like descriptions (with PyTorch MobileNetV2 offline fallback).
  • 45-Meter Geospatial Haversine Deduplication: Eliminates duplicate complaint spam by checking distance radius between new pins and existing tickets on Leaflet/OpenStreetMap.
  • Multilingual Generative NLP: 24/7 session-aware conversational chatbot and dynamic translation engine supporting English, Telugu (తెలుగు), Hindi (हिंदी), and Kannada (ಕನ್ನಡ).
  • Enterprise Security Architecture: PHP 8 REST JSON endpoints, 100% prepared SQL statements, BCRYPT password hashing, zero-leak API keys via environment variables (getenv('GEMINI_API_KEY')), and PHPMailer 6-digit OTP verification.
